# Symptom-Based Disease Prediction System

## Project Overview
This is a Machine Learning-based web application that predicts the most probable disease based on symptoms entered by the user. The system uses the Random Forest algorithm to generate predictions and also provides disease description, medications, precautions, diet suggestions, and workout recommendations.

## Features
- Predicts diseases from user-selected symptoms.
- Uses Random Forest for disease prediction.
- Displays disease description.
- Recommends medications.
- Suggests precautions.
- Provides diet recommendations.
- Suggests workout plans.
- Simple and user-friendly web interface.

## Technologies Used
- Python
- Flask
- HTML
- NumPy
- Pandas
- Pickle
- Random Forest
- CSV Dataset

# How To Run
1. Download or Clone the repository.
2. Install the required libraries.
3. Run app1.py.
4. Open the localhost URL in your browser.
5. Select symptoms and click *Predict*.
